# ERP-08 — RBAC

Les sept profils se connectent. Responsable SAV et chef atelier voient l’OR inter-agence selon leur périmètre ; conseiller et technicien hors périmètre reçoivent 404 ; magasinier voit les pièces mais pas l’OR ; comptable et direction voient la facture mais pas l’OR. Les refus sont 403/404 sans fuite métier.
