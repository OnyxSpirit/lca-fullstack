# ERP-08 — Réserves

- Mettre à jour le kilométrage maître du véhicule lors de la remise, avec règle métier explicite.
- Nettoyer ultérieurement l’OR 1 de recette par un mécanisme métier d’avoir/correction si une base de démonstration parfaitement nette est exigée.
- Requalifier les 39 échecs de campagne globale dans un chantier de stabilisation du harnais indépendant d’ERP-08.
