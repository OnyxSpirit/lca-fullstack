# ERP-11 — Authentification

Connexion valide : 200. Mot de passe erroné et utilisateur inconnu : 401. Ressource sans jeton ou avec jeton invalide : 401. Utilisateur désactivé : connexion 401. Après réactivation, une nouvelle connexion fonctionne. Aucun secret ni jeton n’est conservé dans les livrables.
