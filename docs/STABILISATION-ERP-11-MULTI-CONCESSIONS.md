# ERP-11 — Multi-concessions

La recette couvre une concession et deux agences de cette concession. Aucun scénario destructif ni transfert vers une autre concession n’a été exécuté faute de jeu REC11 dédié. La non-élévation hors périmètre reste assurée par le RBAC dynamique ; couverture multi-concessions : partielle.
