# STABILISATION-ERP-13 — Multi-agences

Le responsable RH de portée concession peut cibler les agences autorisées. Le gestionnaire RH d’agence voit le dossier et le salaire de son agence, tandis que les prédicats SQL empêchent une extension hors scope.

Les sélecteurs frontend présentent les quatre agences actives de recette selon les permissions.
