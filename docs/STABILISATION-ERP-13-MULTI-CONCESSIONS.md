# STABILISATION-ERP-13 — Multi-concessions

Validation statique et contractuelle conforme : catégories, profils et budgets portent une concession ; les prédicats et contrôles de cible interdisent une concession étrangère.

Réserve : la base de recette ne contient qu’une concession et aucun parcours officiel autorisé n’a permis d’en créer une seconde. L’isolation multi-concession réelle demeure donc partiellement vérifiée, sans écriture SQL artificielle.
