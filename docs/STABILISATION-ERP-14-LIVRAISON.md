# ERP-14 — Livraison

Une livraison sur la vente REC14 annulée est refusée (`409`). Les trois livraisons existantes, dont des dossiers livrés avec paiement total ou autorisation, ont été contrôlées en lecture.

Pas de nouvelle livraison REC14 finalisée afin de ne pas dupliquer les preuves irréversibles ERP-06.
