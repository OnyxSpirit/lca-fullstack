# ERP-14 — Notifications

Showroom émet l’événement agence lors de l’affectation. La notification persistante ciblée n’est créée que si le destinataire possède `notifications.view`; le COMMERCIAL REC14 ne la possède pas, donc aucune ligne n’est écrite et aucune fuite n’a lieu.

Cette politique est cohérente avec le service existant mais laisse le producteur Showroom non démontré en persistance pour ce rôle. Les notifications historiques restent 62.
