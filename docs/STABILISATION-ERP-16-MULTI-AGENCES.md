# ERP-16 — Multi-agences et multi-concessions

## Multi-agences

Les profils A2, A3 et A4 démontrent les intersections OWN/AGENCY/CONCESSION/GLOBAL attendues. Les accès transverses non autorisés retournent `403` ou `404` selon la politique de masquage. Le Super Administrateur lit les ressources A2 et A3. Les événements Pièces restent dans la room de l'agence 2.

Statut : **VALIDÉ**.

## Multi-concessions

La base de recette ne contient qu'une concession exploitable et aucun workflow officiel de création d'une seconde concession n'a été utilisé. Aucun contournement SQL n'a été réalisé.

Statut : **BLOQUÉ PAR ENVIRONNEMENT**.
