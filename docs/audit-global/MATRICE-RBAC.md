## Scopes

Le backend définit et exploite les scopes `OWN`, `AGENCY`, `CONCESSION`, `GLOBAL` via le contexte RBAC. La présence d’une permission frontend ne constitue pas une protection; les anomalies de routes ou services sans contrôle démontré sont classées séparément.
