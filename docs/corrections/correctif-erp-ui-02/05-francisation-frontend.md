# Francisation du frontend

Les parcours modifiés utilisent des libellés français. Les identifiants, routes, clés JSON et constantes internes restent inchangés. Les termes consacrés tels que « Showroom » sont conservés.

Réserve : une recette visuelle exhaustive de tous les écrans est nécessaire pour certifier l’absence absolue de texte anglais issu de données ou de réponses serveur.
