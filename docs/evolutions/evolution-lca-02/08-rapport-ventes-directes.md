# Ventes directes

Le même formulaire accepte client enregistré ou tiers libre, plusieurs pièces et fiscalité avec/sans TVA. Aucun client CRM n’est créé pour un tiers. Le backend calcule, réserve puis libère le stock. Les quatre scénarios finaux ont créé les factures 16 à 19 : 71 340 XAF avec TVA et 60 000 XAF sans TVA. La génération PDF tiers est corrigée par les snapshots de facture.
