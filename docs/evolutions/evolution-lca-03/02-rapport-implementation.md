# Implémentation

La migration 136 ajoute les référentiels et snapshots indispensables. Le backend calcule brut, retenues de congés, cotisations salariales, charges patronales et net. Les routes stock conservent les coûts par mouvement, exposent valorisation et acquisitions, et séparent affectation physique et salaire. Les types de contrats sont centralisés dans Paramètres concession.
