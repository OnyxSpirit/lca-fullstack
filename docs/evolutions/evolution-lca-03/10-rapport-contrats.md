# Contrats

Configuration centralisée dans Configuration → Contrats ; le gestionnaire de modèles a été retiré de la fiche employé. CDD : durée standard positive et fin individuelle obligatoire/ajustable. CDI : aucune fin fictive. Les affectations snapshotent nature et durée ; modifier le modèle de 12 à 18 mois conserve 12 sur le premier contrat et inscrit 18 sur le suivant. Les modèles inactifs restent visibles historiquement.
