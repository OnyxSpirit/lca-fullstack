# Guide de recette utilisateur

## EVO-45

1. Module : **Stock véhicules**.
2. Ouvrir un véhicule accessible dans l’agence active.
3. Profil : permission `vehicles.view` avec scope `AGENCY` et permission documentaire existante.
4. Dans la fiche, utiliser l’action d’impression de la fiche véhicule.
5. Vérifier identification, technique, options, garantie et toutes les photos.
6. Cas négatifs : autre agence, permission absente, photo illisible.
7. Attendu : PDF français multipage ; aucune donnée de coût interne ; une photo illisible n’interrompt pas les suivantes.

Les autres parcours suivent les libellés réels des modules listés dans le rapport 02 et leurs permissions documentées dans les rapports 07 à 18.
