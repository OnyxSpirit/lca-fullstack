# Rapport RBAC

La décision est pilotée par la permission et le scope, pas par la différence d’identité entre demandeur et approbateur. Scénarios confirmés : soumission sans approbation refusée ; approbation sans permission refusée ; acteur polyvalent autorisé ; absence de permission refusée ; historique distinct des actions ; agence active conservée.

Les domaines `accounting`, `activity`, `bank_reconciliation`, `proformas` et `supplier_finance` disposent désormais de libellés français. Les valeurs techniques restent les clés internes et ne sont pas altérées.
