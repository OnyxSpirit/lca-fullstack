# Nouvelle stratégie de recette

La qualification est séparée en deux campagnes :

1. Référence indépendante : nouvelles données fictives, base dédiée, scénarios définis à partir du code et des contrats actuels.
2. Non-régression historique : suites existantes conservées et corrigées uniquement lorsque leur attente était démontrée obsolète.

La première campagne décide de la conformité du socle actuel ; la seconde détecte les régressions étendues. Aucun échec historique n'est masqué ou transformé en succès artificiel.
